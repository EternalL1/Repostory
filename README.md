# Repostory

Tools for exploring the story behind a Git repository.

## The app

[`repostory/`](repostory/) is a browser-only app that turns `git log` output into an interactive commit graph (DAG), a merge-base finder, team insights, and **Story**: a tap-through recap of the repo, Wrapped-style, that ends on a poster you can share. Built with React, Vite and Tailwind CSS v4.

Live: https://repostory-mu.vercel.app

```bash
cd repostory
npm install
npm run dev
```

See [`repostory/README.md`](repostory/README.md) for features, how to load your own repo, and the project structure.
